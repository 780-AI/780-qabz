# 006_greeting_ping — Greeting method to ping the service

Status: done

## Description

Add a new service method `Greeting()` with the messages `GreetingRequest {}` and `GreetingResponse` to the `qabz` proto, in the same form as the other service methods (an HTTP rule for grpc-gateway). The request is empty. The method returns the string "Hello". Its only purpose is to ping the service and show that the server works. It can be removed later.

Help: a new message and a new service method need the generated code again (`make proto`).

Points for the design step:
- The `.proto` files are in the `pb` submodule (`pb/proto/qabz/services.proto`), which is a separate repository (`p-source.780.ir/general/backend/pb.git`). The proto change is committed and pushed there first; then this repository moves the submodule pointer to that commit.
- Which service gets the method: the existing `Service` service or a new service (for example `Greeting`).
- `GreetingResponse` cannot be fully empty, because it carries "Hello". The design names the field (for example `string message = 1;`) and the exact JSON body.
- The HTTP verb and path (for example `get: "/v1/greeting"`).
- The App has no gRPC server and no grpc-gateway HTTP server yet. This task adds the smallest server needed (listen addresses as config keys, start and graceful stop in the App). If the operator wants that server as its own task first, this task waits for it.

## Definition of Done

- `GreetingRequest`, `GreetingResponse` and the `Greeting` method are in the `qabz` proto, with an HTTP rule.
- `make proto` generates the Go, gRPC, gateway and swagger code with no error.
- The service implements `Greeting` and returns "Hello".
- A call from Postman to `.../greeting` returns "Hello" with HTTP status code 200.
- Unit tests cover the handler; build, vet and tests pass.
- The submodule pointer, the CHANGELOG and the docs are updated in the same commit.

## Verification

Run the service. Send an HTTP request to the gateway endpoint of `Greeting` (generated by grpc-gateway). The response is "Hello" with HTTP status code 200.

```proto
  rpc Greeting (haf80.api.bill.GreetingRequest) returns (haf80.api.bill.GreetingResponse) {
    option (google.api.http) = {
      get: "/v1/greeting"
    };
  }
```

Add at the end of the file:

```proto

message GreetingRequest {}
```
